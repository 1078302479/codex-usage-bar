# CodexUsageBar artwork

`CodexUsageBarAppIcon.png` is the app icon artwork. An amber gauge surrounds a white terminal chevron and a rounded lavender cursor on a graphite tile. `MakeIcon.swift` generates the complete macOS iconset from this asset.

The popover and settings use the packaged app icon. The menu bar uses the separate white Codex service mark generated by `ProviderIcon.swift`.
