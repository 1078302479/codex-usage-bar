# CodexUsageBar artwork

`CodexUsageBarAppIcon.png` is the user-approved composite preview: white terminal chevron and two quota bars on a bright blue rounded-square backplate. `MakeIcon.swift` generates the complete macOS iconset from this asset.

The transparent counterpart is generated by `ProviderIcon.swift`: the earlier Codex lobed terminal mark without a tile. Menu-bar artwork stays white; the popover title uses the same mask tinted with the accent color for legibility. The earlier CodexServiceIcon.png is an unused design reference and is not included in the application bundle.
