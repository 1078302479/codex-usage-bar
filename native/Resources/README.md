# CodexUsageBar artwork

`TideIcons` contains the Tide icon artwork. The app ships with the default double rings and uses `rings-template.png` for the text-based menu bar layouts.

`MakeIcon.swift` builds the bundled `TideRings.icns` from `TideIcons/rings.png`. The bundle also includes `AppIcon.icns` for compatibility with existing updaters. `CodexUsageBarAppIcon.png` is the previous graphite gauge artwork.

Appearance and About show the selected artwork. The single-line and stacked-text menu bar layouts use the matching template.
