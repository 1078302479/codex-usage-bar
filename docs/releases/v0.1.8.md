# v0.1.8 — 多账号管理测试版 / Multi-account preview

- 支持多个独立登录；当前客户端用户为主账号，Plus 备用账号优先。
- 首页原地管理账号，与设置页联动；可添加、登录、退出及删除。未登录条目不占首页。
- 删除二次确认、即时进度、失败保留；成功即移除，进程清理在后台完成。
- 账号卡片内“↔ 切换”，更多菜单包含重新登录、退出登录、删除。
- 共用本地工作空间及模型提供商配置，凭证独立；修改前备份配置和本地状态，不导入备用目录历史。
- 1～2 个已登录账号显示 Token 活动，重置卡明细默认收起；3 个及以上隐藏 Token 活动、默认展开明细。仍可手动调整。
- Free 账号只显示一个额度进度条；Plus / Free 标签加强区分。

## 试用说明

macOS 14+，Apple Silicon（arm64）。拖动 DMG 内应用到 Applications，或解压 ZIP。此包为 ad-hoc 签名，未经 Apple 公证。

升级保留已有账号设置。切换账号会请求客户端正常退出并重启，请先保存任务；若无法核验执行账号则禁用切换。客户端内部接口随版本变化，切换后请核对客户端实际登录用户。已在本机验证双账号识别与 CLI 协议；真实第三个及更多账号的完整登录/切换、不同机器上的界面与升级兼容性仍需用户试用验证。测试通过不代表上述真实场景全部验收。

请重点反馈：添加/退出/删除、删除取消与失败、Plus 排序、Free 单进度条、切换后的项目与模型配置、2↔3 个已登录账号时的展示变化。

## English

Multi-account management is available directly in the popup and Settings. The current desktop user is primary; Plus backups sort first. Credentials remain isolated while local workspace and provider settings are shared. Deletion requires confirmation and removes the entry after successful logout without waiting for process cleanup.

For 1–2 signed-in accounts, Token activity is visible and credit details start collapsed; for 3+, activity is hidden and details start expanded. Free accounts show one quota bar. Requires macOS 14+ on Apple Silicon. Ad-hoc signed, not notarized. This is a preview: full real-account switching with 3+ users and compatibility on other machines still require testing. Save work before switching and verify the desktop login afterward.
