# CodexUsageBar v0.1.7 — 修复客户端更新后切换账号项目列表为空

## 重点修复

更新 ChatGPT macOS 客户端后，使用“切换并重启”进入备用账号，可能出现侧边栏已有项目全部不见、切回原账号又能看到的情况。

本次已确认的原因是新版客户端按账号保存并恢复桌面项目状态：即使两个账号共用同一项目数据库，登录时恢复的空项目列表仍会覆盖当前显示状态。这次排查中的项目文件和数据库记录仍然存在，不需要重新创建项目。

v0.1.7 在客户端正常退出后同步本地项目列表、排序、会话归属及项目映射，并处理账号缓存恢复覆盖列表的问题。当前列表为空且只有一个非空账号缓存时，从该缓存恢复；存在多个候选时停止自动恢复，避免猜测。改写前保留原状态备份；不复制认证凭证，不改动账号专属界面设置。

## 已遇到问题的用户如何升级

1. 退出旧版 CodexUsageBar，将新版拖入 Applications 替换并启动。
2. 保存内容并结束正在运行的任务，使用 CodexUsageBar 的“切换并重启”切回原账号。
3. 再切换到备用账号，确认已有项目与会话正常显示。修复在切换退出后执行，仅安装而不切换不会立即刷新运行中的客户端。

请勿因列表为空而删除工作区或重新创建同名项目。修复备份保存在对应 Codex 目录的 `.codex-global-state.json.workspace-backup-*`，排障时请勿公开上传此类个人状态文件。

## 其他改进

- 重置卡到期提醒跟随当前执行账号，备用账号不重复发送；账号身份尚未确认时暂停安排提醒。
- 继续聚焦 Codex 额度与双账号管理，不包含网络流量监测。

- 在 ChatGPT macOS 26.1103.31037 上完成实际双账号切换，用户确认项目列表恢复。

## English

Fixes existing projects disappearing after switching accounts following a ChatGPT macOS update. Newer clients restore account-specific desktop project state; an empty account cache can hide projects even while both backends use the same database.

The app now synchronizes local workspace metadata and account-cached project fields after a graceful client exit. It restores an empty list only when exactly one nonempty account cache is available, backs up changed state, and keeps credentials and account-specific UI settings separate.

Upgrade the app in Applications, finish running work, switch back to the original account using Switch and Restart, then switch to the alternate account again. Installation alone does not refresh the running client's state. Do not delete workspaces or recreate missing projects. State backups use `.codex-global-state.json.workspace-backup-*` and should remain private.

Reset-credit reminders now follow the active execution account. Tested with native regressions and a user-confirmed real account-switch round trip on ChatGPT macOS 26.1103.31037. Apple Silicon, macOS 14+, ad-hoc signed and not notarized. Other or future client versions may require further compatibility work.
