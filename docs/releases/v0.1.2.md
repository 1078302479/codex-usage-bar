# CodexUsageBar v0.1.2

后台资源优化 / Background resource improvements

## 中文

- 设置窗口关闭后释放窗口及 SwiftUI 视图，下次打开重建，保留显示偏好。
- 额度弹窗关闭后释放视图，减少隐藏界面计算与绘制；额度监听、核验和菜单栏更新继续工作。重新打开恢复当前数据与本次运行的高度偏好。
- 菜单栏内容未变化时复用图像，避免重复创建。
- 启动日志扫描只保留最近 24 个候选，逐文件释放临时对象；仍会遍历日志目录。

验证：39 项核心断言、9 项热力图检查、1,000 个日志候选筛选、30 次设置窗口和 100 次弹窗开关资源释放检查、真实文件追加监听与去重。尚未量化内存节省，也未完成连续 8 小时运行或真实休眠唤醒的内存验收。

更新：退出旧版，下载 DMG，将 CodexUsageBar 拖到 Applications 并替换，再从“应用程序”启动。沿用原 bundle identifier，保留现有偏好。

## English

- Release settings windows and their SwiftUI views on close; recreate them on reopening while retaining preferences.
- Release hidden quota-panel views while quota monitoring, validation, and menu bar updates continue. Reopening restores current data and panel height for the current run.
- Reuse unchanged menu artwork instead of recreating images.
- Retain only the newest 24 startup log candidates and drain per-file temporary objects; directory enumeration still occurs.

Validation covers 39 core checks, 9 heatmap checks, selection across 1,000 logs, resource release over 30 settings-window and 100 panel cycles, and live filesystem change detection/deduplication. Memory savings have not been quantified; eight-hour uptime and real sleep/wake memory behavior remain unverified.

Update: quit the previous app, open the DMG, drag CodexUsageBar to Applications and replace the old copy, then launch from Applications. Existing preferences are retained under the same bundle identifier.
