# CodexUsageBar v0.1.4

重置卡提醒、自定义菜单栏颜色与全新额度界面 / Reset-credit reminders, menu-bar colors and refreshed quota UI

## 中文

- 新增重置卡数量、每张卡的到期明细和最近到期倒计时。直接展示未来 72 小时内到期数量；明细不全时标注“已知”或“待确认”，不推算未知日期。
- 新增“重置卡提醒”设置，默认关闭。主动开启时申请 macOS 通知权限，并重新核验账号；每张卡在到期前 24 小时提醒一次，首次开启或唤醒时进入提醒范围的卡片会在核验后补提醒。
- 提醒按账号、卡片和到期时间持久去重，检测到使用、过期、账号变化或关闭提醒后取消对应通知。开启提醒后每 15 分钟及已知提醒边界前核验，保留现有错误退避。
- 5 小时和 7 天菜单栏百分比可分别设置多条颜色区间，支持横排和堆叠。区间包含两端边界，重叠时以上方优先；未命中或未知时保持原默认颜色。默认没有自定义规则，旧设置保留。
- 更新环形额度仪表、紧凑账号与套餐标签、到期提醒横条、活动统计和状态摘要；保留原应用图标。
- 优化深色模式：柔和石墨灰背景、清晰的辅助文字、低饱和强调色及无密集描边的热力图。
- 应用只读额度和卡片状态，不会自动使用重置卡。

## English

- Show reset-credit counts, per-card expiry details, nearest-expiry countdown and the number expiring within 72 hours. Incomplete details are explicitly marked; unknown dates are never guessed.
- Add opt-in local notifications 24 hours before expiry. Enabling requests macOS permission and fresh account validation; catch up after validation when already inside the reminder window.
- Persist account/card/expiry deduplication and cancel reminders after detected usage, expiry, account changes or opt-out. Opted-in users receive 15-minute and pre-reminder checks, respecting retry backoff.
- Configure independent percentage color ranges for short- and long-term menu-bar quotas in horizontal and stacked layouts. Endpoints are inclusive; the first matching rule wins. Unmatched or unknown quotas retain the original default color. Existing preferences are preserved.
- Introduce circular quota gauges, a compact account/subscription header, expiry notices, activity statistics and a concise status footer while retaining the original app icon.
- Improve dark-mode legibility with a graphite background, clearer secondary text, subdued accents and a quieter heatmap.
- Read-only: reset credits are never consumed automatically.

## 验证与限制 / Validation and limitations

原生回归覆盖额度格式、颜色匹配与持久化、72 小时边界、通知权限/去重/取消/并发、账号初始化、休眠唤醒及连接恢复。真实账号的额度和卡片读取、浅色主面板已验证。最终深色主面板截图检查未完成；系统通知横幅、权限弹窗和跨重启投递尚未实测。

Native regressions cover quota formatting, color matching/persistence, 72-hour boundaries, notification permission/deduplication/cancellation/races, account initialization, sleep/wake and connection recovery. Live account/card reads and the light panel are verified. Final dark-panel screenshot review, actual notification banners/permission prompts and reboot delivery remain unverified.

正常退出保留已安排的本地通知；其他设备用卡需再次核验才能取消。休眠、关机和专注模式可能延迟投递。只有数量而无到期明细时无法安排提醒。

Normal quit preserves scheduled notifications. Remote-device usage requires another validation to cancel them; sleep, shutdown and Focus can delay delivery. Reminders require known expiry details.
