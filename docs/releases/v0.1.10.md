# v0.1.10 — 应用内更新正式版 / In-app updates

本次正式发布应用内更新功能，并包含多账号管理、首页登录/退出/删除、账号卡片切换及本地工作空间共享。

## 更新内容

- 应用内展示新版本说明。
- 自动选择当前芯片对应的 ZIP 安装包（当前发布包为 Apple Silicon / arm64）。
- 校验文件大小、SHA-256、应用标识、版本、代码签名和架构，验证失败停止安装。
- 用户确认“安装并重启”后才替换应用，仅重启 CodexUsageBar，不重启 ChatGPT。
- 旧版本保留为备份；替换失败或启动请求失败时尝试恢复。
- 新增“接收测试版”，默认关闭，设置持久保存。

## 从本地 0.1.9 在线升级

1. 打开“设置 → 连接与更新 → 软件更新”。
2. 点击“立即检查更新”，正式版无需开启“接收测试版”。
3. 确认发现 v0.1.10，点击“查看版本说明与更新”。
4. 点击“下载并校验”，等待提示校验通过。
5. 点击“安装并重启”，重新打开设置确认版本为 0.1.10。

应用目录须可写。首次尝试前可保留旧安装包。失败状态会在更新界面展示，安装日志位于 `~/Library/Application Support/CodexUsageBar/updates/install.log`。

## 其他用户

v0.1.8 及之前尚未内置自动安装能力，需手动下载安装一次本版。支持 macOS 14+、Apple Silicon；采用 ad-hoc 签名，未做 Apple 公证。保留已有多账号功能及本地工作空间，不修改登录配置。

本地已验证真实 GitHub 下载与校验链路、安装/重启及替换或启动请求失败的回滚测试；不同机器的完整升级仍待试用反馈。更新不是静默安装，必须点击安装并重启。

## English

Review release notes in-app, download the architecture-matched ZIP, validate size/SHA-256/bundle identity/version/signature/architecture, then explicitly install and restart. Only CodexUsageBar restarts. The previous bundle is retained; replacement or launch-request failures attempt rollback. Preview releases remain opt-in; this stable release does not require that option.

Local v0.1.9 users: check for v0.1.10, download and verify, then install and restart. v0.1.8 and earlier require one manual upgrade. Requires writable app installation directory, macOS 14+ and Apple Silicon. Ad-hoc signed, not notarized. Existing multi-account settings and local workspace are retained.
