# v0.1.10 — 多账号管理与应用内更新 / Multi-account management and in-app updates

本次正式版整合多账号管理、本地工作空间共享和完整的应用内更新流程。

## 多账号管理

- 支持添加多个独立登录账号，当前客户端登录用户显示为“主账号”。
- 备用账号按 Plus 优先排序，同套餐保持添加顺序，编号为“备用账号 1…N”。
- 首页原地添加、登录、退出和删除账号，与设置页共用同一份数据；未登录条目不占首页。
- 账号标签旁提供“↔ 切换”，更多菜单包含重新登录、退出登录和删除。
- 删除需二次确认，等待时显示进度；成功后立即从首页和设置列表移除，后台清理不阻塞界面，失败则保留账号。

## 本地工作空间与额度展示

- 多账号共用本地项目、聊天和模型提供商配置，登录凭证独立；切换账号时工作空间不跟着变化。
- 修改前备份配置和本地状态，不导入备用目录历史，不从其他账号缓存恢复或合并项目，不请求云端项目与聊天同步。
- 1～2 个已登录账号显示 Token 活动，重置卡明细默认收起；3 个及以上隐藏 Token 活动，明细默认展开，仍可手动调整。
- Free 账号只显示一个额度进度条，Plus / Free 标签加强区分。

## 应用内更新

- 在应用内查看新版本说明，下载匹配当前芯片的 ZIP 安装包。
- 校验文件大小、SHA-256、应用标识、版本、代码签名和架构，验证失败停止安装。
- 用户确认“安装并重启”后才替换应用，仅重启 CodexUsageBar，不重启 ChatGPT。
- 旧版本保留为备份；替换失败或启动请求失败时尝试恢复。
- 默认检查正式版，可选择开启“接收测试版”，设置持久保存。

## 安装说明

支持 macOS 14+、Apple Silicon（arm64）。v0.1.8 及之前需手动下载安装一次本版，以获得新的应用内更新功能。安装包采用 ad-hoc 签名，未经 Apple 公证。

升级保留账号设置和本地工作空间。切换账号会重启客户端，请先保存任务；客户端内部接口可能随版本变化，切换后请核对实际登录用户。

## English

### Multiple accounts

- Add independent account logins. The desktop client's current user is primary; Plus backups sort first, with insertion order preserved within each tier.
- Manage accounts directly in the popup or Settings using shared data. Unsigned entries are hidden from the home view.
- Switch from each backup card. The more menu provides re-login, logout and deletion. Deletion requires confirmation, shows progress, and removes the entry immediately on success; failures retain it.

### Local workspace and quota display

- Credentials remain separate while local projects, chats and provider settings share one workspace. Existing secondary files are backed up rather than imported; switching does not fetch cloud projects/chats or restore projects from other account caches.
- With 1–2 signed-in accounts, Token activity is shown and credit details start collapsed. With 3+, activity is hidden and details start expanded. Manual adjustment remains available.
- Free accounts show one quota bar; Plus and Free badges are easier to distinguish.

### In-app updates

Review release notes, download the architecture-matched ZIP, validate size/SHA-256/bundle identity/version/signature/architecture, then explicitly install and restart. Only CodexUsageBar restarts. The previous bundle is retained; replacement or launch-request failures attempt rollback. Preview releases are opt-in.

Requires macOS 14+ and Apple Silicon. v0.1.8 and earlier require one manual upgrade to obtain the updater. Ad-hoc signed, not notarized. Existing account settings and local workspace are retained. Save work before switching accounts and verify the desktop login after restart.
