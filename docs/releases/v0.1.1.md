# CodexUsageBar v0.1.1

CodexUsageBar 首个公开版本：在 macOS 菜单栏查看 Codex 额度、重置时间与官方 Token 活动。

## 中文

- 读取当前 Codex 登录账号的短期/7 天剩余额度、重置时间与套餐信息。
- 菜单栏可自定义指标、描述、分隔符和图标；支持 7 天在上、5 小时在下的双行模式。
- 官方累计 Token、单日峰值、最长单轮与活跃连续天数；26 周活动热力图支持即时提示。
- 深浅外观、随内容展开与拖动调节的面板、macOS 登录项开关。
- 默认监听本机额度变化后向服务商核验，不把日志估算当作当前账号的官方额度。

安装：下载 DMG，将应用拖入 Applications，推出磁盘后从“应用程序”启动。更新前退出旧版 UsageBar/CodexUsageBar。

系统：Apple Silicon，macOS 14+，本机 Codex 已通过 ChatGPT 账号登录。当前 UI 为中文。首版为临时签名，未做 Developer ID 签名或公证。自动登录启动尚未做重启验收；统计可能延迟，不能保证跨设备即时同步。

## English

First public release of CodexUsageBar, a native macOS menu bar monitor for Codex allowance and official account activity.

- Short-term and weekly remaining allowance, reset times, and plan information.
- Configurable menu bar metrics, labels, separators, icons, and two-row layout.
- Official account token summaries and a 26-week daily activity heatmap with immediate details.
- Light/dark/system appearance, an expanding/resizable panel, and login-item controls.
- Local event following with service-side validation, rather than inferred account-wide usage.

Install by opening the DMG and dragging the app to Applications. Quit older copies first. Requires Apple Silicon, macOS 14+, and a local Codex installation signed in with ChatGPT. The current UI is Chinese. This release is ad-hoc signed, not Developer ID signed/notarized. Reboot/login startup has not been validated; aggregate activity may lag and cross-device synchronization is not instantaneous.
