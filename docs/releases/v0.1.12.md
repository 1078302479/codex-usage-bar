# v0.1.12 — 新版界面与当前账号聚焦

## 更新内容

- 重做主弹窗和设置页面，统一模块背景、边框、文字层级和操作入口。
- 账号卡片展示完整邮箱、套餐和账号数量；展开菜单区分“当前登录”和“正在查看”，集中提供“切换并重启”和账号管理入口。
- 临时查看备用账号不会改变菜单栏数据来源。关闭弹窗后自动恢复当前登录账号，重新打开时直接显示其额度；当前登录的是备用账号时同样适用。
- 额度概览使用双周期百分比和进度条，Free 账号按实际周期展示；优化重置卡时间线、累计 Token 摘要及活动页。
- 修正多账号身份匹配中的重复身份确认逻辑，完整邮箱兼容旧版缓存。

## 从当前版本手动检查更新

1. 打开 CodexUsageBar 的“显示与连接设置…”。
2. 进入“连接与更新”，点击“立即检查更新”。
3. 查看 v0.1.12 版本说明，点击“下载并校验”。
4. 校验完成后，点击“安装并重启”并确认。
5. 重新启动后，在设置中确认版本为 0.1.12。

更新应用只重启 CodexUsageBar；账号菜单里的“切换并重启”则会重启客户端，两者用途不同。账号、偏好和应用包外的本地工作空间保留。

## 安装包与验证范围

支持 macOS 14 及以上、Apple Silicon（arm64）。附件包含 DMG、供应用内更新使用的 ZIP，以及 SHA256SUMS.txt。不提供 Intel 构建。

本次发布执行原生回归、构建、DMG 检查和 ZIP 更新器验证。新版界面及账号选择已在本机预览检查；完整的线上手动升级体验留待用户本次验证。安装包使用 ad-hoc 签名，未经过 Apple 公证。

## English

Redesigned native popover and settings with full-email account cards, a clearer account menu, quota bars, reset-credit timelines and Token activity. Browsing another account is temporary: closing the panel restores the active login, while the menu bar always follows that login.

To update, open Settings → Connection & Updates, check now, review v0.1.12, download and verify, then install and restart. Requires macOS 14+ and Apple Silicon. Ad-hoc signed, not notarized. End-to-end online update acceptance remains for user testing.
