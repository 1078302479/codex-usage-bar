# CodexUsageBar v0.1.5

账号切换与应用路径兼容修复 / Account switching and application path fixes

## 中文

- 修复选择 `ChatGPT.app`、`Codex.app` 或 `CodexCLI.app` 后无法读取额度：自动定位应用内部的 Codex 可执行文件，同时保留直接选择 CLI 和留空自动发现。
- 无效目录不再被当作可执行文件启动，改为显示明确的路径配置提示。
- 手动刷新会清除旧账号展示并重建连接，重新读取其他 Codex 进程切换后的登录状态，避免复用过期认证。
- 显示“需要登录”时，定时核验在至少 60 秒冷却后尝试重建连接；无需反复退出工具，不会自动发起登录或打开浏览器。
- 区分初始化账号通知与运行中的账号变化，避免初始化时反复失效及影响超时恢复。
- 补充重置卡使用后的额度兜底核验：默认面板显示时每 15 秒、后台每 60 秒核验额度，不额外查询 Token 活动；保留自选更新间隔、错误退避及休眠暂停。
- 重置卡到期倒计时统一显示为“天、小时、分钟”。

## English

- Resolve the embedded Codex executable when selecting `ChatGPT.app`, `Codex.app`, or `CodexCLI.app`. Direct executable selection and automatic discovery remain supported.
- Reject directories as executables and show actionable path configuration guidance.
- Manual refresh clears previous account presentation and recreates the connection to reload authentication after an external account switch.
- After an authentication failure, polling can recreate the connection following a minimum 60-second cooldown, without starting a login flow or opening a browser.
- Distinguish initial account announcements from runtime account changes to preserve initialization and timeout recovery.
- Reconcile quota after reset-credit usage even without a local event: in default mode, check quota every 15 seconds with the panel open or 60 seconds in the background. These checks do not fetch Token activity and respect custom intervals, backoff and sleep.
- Display reset-credit expiry countdowns consistently in days, hours and minutes.

## 验证与限制 / Validation and limitations

已通过原生回归与真实 stdio 传输测试，覆盖应用路径解析、外部账号切换、旧账号数据清理、登录恢复限频、子进程重启、超时及休眠唤醒。已在本机核验切换后的真实账号额度与 Token 活动。

Native regressions and real stdio fixture tests cover bundle discovery, external account switching, stale account removal, auth recovery throttling, process restart, timeout and sleep/wake. Live quota and Token activity have been verified for the switched account on the maintainer's Mac.

安装后先退出旧版，将应用拖入 Applications，替换后重新打开。保留原有偏好设置。自动登录恢复的检查时机仍受用户所选更新间隔影响；手动刷新可立即重建连接。

Quit the old version, drag the app into Applications, replace it and reopen. Existing preferences are retained. Automatic auth recovery follows the selected polling interval; manual refresh reconnects immediately.
