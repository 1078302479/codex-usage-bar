# v0.1.11 — 在线更新体验完善 / Improved in-app updates

本次更新完善 CodexUsageBar 的在线升级体验：下载进度更清晰，安装前再次确认，并加强安装包检查与失败恢复。已有 v0.1.10 的用户可以直接在应用内检查并升级。

## 更新内容

- **下载进度与取消**：下载时显示百分比，支持随时取消；校验通过后再提供安装入口。
- **安装前再次确认**：点击“安装并重启”后会再次确认，确认后才退出并替换 CodexUsageBar，不会重启 ChatGPT。
- **更可靠的检查入口**：GitHub API 不可用或限流时，尝试通过官方最新发布页识别正式版本，并引导到发布页手动下载。缺少适合本机的 ZIP 或校验文件时，也提供手动下载入口。
- **自动检查节奏优化**：启动时及运行期间每小时触发检查，距离上次成功检查不足 24 小时则跳过；手动检查不受限制。默认使用正式版，可选择接收测试版。
- **安装包检查加强**：检查下载大小、SHA-256，以及 GitHub 提供的附件 digest；解压前检查路径、文件类型与解压大小，解压后检查应用标识、版本、必要资源、签名完整性和处理器架构。
- **备份与失败恢复**：替换前再次校验暂存应用的签名，保留旧版本备份；替换失败或启动命令失败时尝试恢复旧版。应用目录不可写时，可点击“查看安装文件”进行手动替换。

## 如何体验在线更新

1. 在 v0.1.10 中打开 **设置 → 连接与更新 → 软件更新**。
2. 点击 **立即检查更新**，再点击 **查看版本说明与更新**。
3. 点击 **下载并校验**，等待安装包通过检查。
4. 点击 **安装并重启**，在确认框中确认，等待 CodexUsageBar 重新启动。
5. 在设置中核对版本为 **0.1.11**。

升级保留应用包外的账号、设置和本地工作空间。安装前请保存正在进行的任务。v0.1.8 及更早版本需要先手动下载安装新版，才能使用这套应用内更新流程。

## 安装与下载

支持 **macOS 14 及以上、Apple Silicon（arm64）**。本次未提供 Intel 安装包。

| 附件 | 用途 |
| --- | --- |
| `CodexUsageBar-0.1.11-mac-arm64.dmg` | 首次安装或手动升级，打开后将应用拖入 Applications |
| `CodexUsageBar-0.1.11-mac-arm64.zip` | 应用内在线更新使用，也可手动解压安装 |
| `SHA256SUMS.txt` | DMG 和 ZIP 的 SHA-256 校验清单 |

## 验证范围与已知限制

- 已通过完整原生回归、应用构建、DMG 完整性检查，以及实际 ZIP 的更新器解压与应用验证。
- 发布后已重新下载 GitHub 附件，确认 DMG、ZIP 的 SHA-256 与校验清单一致，并通过远端 ZIP 的更新器验证。
- 新增发布预检与发布脚本，发布前核对源码及附件是否与通过检查时一致。
- 实机在线升级流程尚未完成人工验收；回滚覆盖应用替换和启动命令失败，不检测新版本启动后是否崩溃。
- 当前安装包使用 **ad-hoc 临时签名，未经过 Apple 公证**；签名完整性检查尚未固定开发者 Team ID。自动更新暂不支持含符号链接的安装包。

## English

This release improves the in-app update experience with download progress, cancellation, a second installation confirmation, stricter package validation and backup recovery.

- Automatic checks run at startup and hourly, skipping checks within 24 hours of the last success. Manual checks bypass this delay; preview releases remain opt-in.
- If the GitHub API is unavailable or rate-limited, stable-release detection falls back to the official latest-release page and offers manual downloading.
- Downloads are checked for size, SHA-256 and GitHub asset digest when provided. Archive paths, file types and expanded size are checked before extraction; bundle identity, version, resources, signature integrity and architecture are checked afterward.
- Installation restarts only CodexUsageBar and retains external accounts, settings and the local workspace. The previous app is backed up; replacement or launch-command failures attempt rollback. Post-launch crashes are not detected.

**Upgrade from v0.1.10:** Open Settings → Connection & Refresh → Software Update, check now, review the release, download and verify, then choose Install and restart and confirm. Verify version 0.1.11 afterward. v0.1.8 and earlier require a manual upgrade first.

Requires macOS 14+ and Apple Silicon. Use the DMG for manual installation; the ZIP supports in-app updates; `SHA256SUMS.txt` contains checksums. Intel builds are not included.

Native regressions, build, DMG integrity and ZIP updater validation passed. Published assets were downloaded again and verified. A real-machine online upgrade has not yet been manually accepted. Ad-hoc signed, not notarized; no fixed developer Team ID requirement. Archives containing symlinks are not supported for automatic installation.
